# Taskbar Media

Управление музыкой и визуализация звука прямо в панели задач Windows 10. Название трека,
исполнитель, обложка, волна или частотный спектр. Музыка остаётся в привычном плеере.
Программа написана на Rust с нативным интерфейсом Windows.

[English](README.md)

## Возможности

- Информация о треке, предыдущий трек, воспроизведение/пауза и следующий трек через медиасессии Windows.
- Захват звука дерева процессов текущего плеера или всего устройства вывода по выбору.
- Волна и спектр из 32 полос, слитная или раздельная отрисовка, 15 или 30 кадров в секунду.
- Амплитуда, время затухания, системный выбор цвета с сохранением 16 пользовательских цветов.
- Изменяемая ширина, компактный режим или вся высота панели задач, обложка и прозрачный фон.
- Независимое скрытие кнопок воспроизведения и настроек. Меню по правой кнопке остаётся доступным.
- Системная, светлая и тёмная темы, высокая контрастность, масштабирование DPI, русский и английский.
- Обновления по событиям. Захват и FFT прекращаются при паузе, скрытии, выключенной визуализации
  и когда для её отображения нет места.
- Настройки рядом с программой. Без кэша изображений, файлов журналов и задач автозапуска.
- Отдельное окно и CLI для управления медиасессиями и анализа звука.

## Требования

Windows x64. Встраивание использует механизм DeskBand Windows 10 и проверено на Windows 10
22H2, сборка 19045. Штатная панель задач Windows 11 этот компонент не поддерживает;
на ней доступно отдельное окно. Для медиасессий нужна Windows 10 1809 или новее.

Плеер должен предоставлять системную медиасессию. **Источник звука > Только плеер** определяет
дерево его процессов по имени исполняемого файла или идентификатору приложения из медиасессии.
Для этого требуется поддержка process loopback в Windows; захват проверен на сборке 19045.
Если API недоступен или процесс нельзя однозначно определить, выводится ошибка. Режим
**Весь звук устройства** включает остальные приложения и уведомления.

Звуки внутри одного дерева процессов не разделяются. Это относится и к вкладкам браузера,
использующим общее дерево. Защищённое аудио может быть недоступно. Отключение аудиоустройств,
сон/возобновление и переходы панели задач между мониторами требуют более широкой проверки
на реальном оборудовании.

## Использование

Скачайте ZIP из [Releases](https://github.com/dyrb/taskbar-media/releases/latest), распакуйте
все три бинарных файла в одну папку и запустите `taskbar-media-ui.exe` на Windows 10.
Программа зарегистрирует компонент и попросит Windows показать **Taskbar Media**.
Подтвердите системный запрос панели инструментов, если он появится. Компонент также доступен
в меню **Панели инструментов** панели задач.

Правая кнопка мыши или кнопка с тремя точками открывает настройки. Чтобы менять ширину
стандартным разделителем, открепите панель задач. Также можно выбрать ширину в меню.
**Высота > Во всю высоту панели задач** следует за высотой контейнера; компактный режим
выравнивает содержимое по верху. Обложка заполняет свою область с обрезкой по центру.
**Цвет...** открывает системный диалог с вводом RGB и пользовательской палитрой.
По умолчанию обложка выключена.

Tab переключает кнопки, пробел активирует выбранную, Shift+F10 открывает меню настроек.
Команды, которые не поддерживает плеер, недоступны. При нехватке места кнопки скрываются,
а при пустой области визуализации останавливается анализ звука. Когда место появляется,
захват возобновляется. Подписки на медиасессию продолжают обновлять информацию о треке.

Для отдельного окна:

```powershell
.\taskbar-media-ui.exe --window
```

### Файлы и регистрация

| Файл | Назначение |
| --- | --- |
| `taskbar-media-ui.exe` | Включение виджета, отдельное окно с `--window` |
| `taskbar-media.exe` | Командная строка и регистрация компонента |
| `taskbar_media_band.dll` | Компонент панели задач Windows 10 |
| `TaskbarMedia.ini` | Создаётся рядом с программой при изменении настроек |

Оставляйте бинарные файлы в зарегистрированной папке. Настройки заменяются атомарно через
`TaskbarMedia.ini.tmp`. Если папка недоступна для записи, программа показывает ошибку;
запасной папки в AppData нет. Запуск и закрытие без изменения настроек не создают INI.
Обложки хранятся только в памяти.

Обычно регистрация записывается в раздел COM текущего пользователя. При отключённом UAC
и запуске с повышенными правами автоматически выбирается системная регистрация. Параметры
`--user` и `--machine` задают область явно; для системной регистрации нужны права администратора.
Windows может запомнить включённую панель между входами в систему. Программа не добавляет
собственных записей автозапуска.

Перед обновлением отключите компонент. Проводник может удерживать DLL после скрытия;
если файл занят, замените его после выхода из системы или самостоятельного перезапуска
Проводника. Программа не перезапускает его автоматически. Для удаления регистрации
используйте ту же область, в которой компонент включался:

```powershell
.\taskbar-media.exe disable
.\taskbar-media.exe unregister
```

### Командная строка

```powershell
# Текущий трек и доступные медиасессии Windows.
.\taskbar-media.exe status
.\taskbar-media.exe sessions

# Изменения медиасессии в течение 30 секунд.
.\taskbar-media.exe watch --seconds 30

# Анализ всего звука устройства вывода в течение 10 секунд.
.\taskbar-media.exe meter --seconds 10 --spectrum

# Идентификаторы устройств вывода и состояние компонента панели задач.
.\taskbar-media.exe devices
.\taskbar-media.exe band-status
```

`meter --process PID` захватывает дерево процессов; `meter --device ID` выбирает устройство
из списка `devices`. Команды `play`, `pause`, `toggle`, `next`, `previous` и `stop` управляют
текущей медиасессией. Ctrl+C останавливает наблюдение. `artwork` выводит размеры системной
обложки без сохранения картинки. Все параметры: `taskbar-media.exe help`. CLI на английском.

## Сборка из исходников

Установите [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/)
с компонентом **Разработка классических приложений на C++** и Windows SDK. Затем установите
Rust через [rustup](https://rustup.rs/) с инструментами MSVC. Нужен Rust 1.88 или новее.
Скачайте архив исходников или клонируйте репозиторий и откройте PowerShell в папке проекта:

```powershell
cargo build --release --locked
```

Три бинарных файла находятся в `target\release`. Сторонних Cargo-зависимостей нет;
ресурсы Windows создаёт `build.rs`. Используются два потока сборки и статическая библиотека
среды выполнения C. Чтобы получить ZIP и SHA-256 без локальных путей сборки:

```powershell
.\scripts\build-release.ps1
```

Результат записывается в `dist`. Скрипт не регистрирует и не публикует компонент.

### Проверки разработки

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
```

Тесты проверяют ABI Windows, владение COM, отмену операций, аудиоформаты, FFT, частотные
полосы, декодирование WIC, настройки и размеры при разных DPI. Две интеграционные проверки
включаются отдельно; обычные тесты не регистрируют компонент в Проводнике и не управляют
воспроизведением. CI выполняет проверки на Windows; тег релиза запускает сборку ZIP
с подтверждением происхождения сборки GitHub.

## Устройство программы

Уведомления медиасессий Windows предоставляют информацию о треке и управление. WASAPI
передаёт звук по событиям. Анализатор использует фиксированные буферы и FFT на 1024 точки.
Интерфейс получает последний кадр без накопления очереди. Непересекающиеся полосы спектра
распределены по Mel-шкале и отображаются в фиксированном диапазоне от -60 до 0 дБ.
Для отрисовки используются GDI и буферизованная отрисовка Windows.

Обложки декодирует Windows Imaging Component. Ограничения: 8 МиБ входных данных,
16 миллионов исходных пикселей, результат до 512x512. Скрытие визуализации отменяет захват;
уже выполняющаяся операция завершается кооперативно. Медиадвижок продолжает обслуживать
информацию о треке и кнопки. Компонент панели задач работает внутри Проводника, поэтому
его потребление ресурсов учитывается в процессе Проводника.
